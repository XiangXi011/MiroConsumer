# P1-4: PRD 补充传播学理论依据

## 目标
在 `PRD.md` 中补充社会科学理论引用，为传播事件分类、可见性分层和社会角色映射建立学术根基。

## 要求

### 必须做
1. 在 PRD.md 中新增一个章节「理论依据」或在相关设计点处嵌入理论引用
2. 至少引用 3 个传播学/社会心理学理论：
   - **Rogers 创新扩散理论**（Diffusion of Innovations）— 对应传播事件分类中的正面传播和质疑挑战
   - **Katz & Lazarsfeld 两级传播理论**（Two-Step Flow）— 对应 social_topology 中的 bridge/amplifier 角色
   - **Granovetter 弱连接理论**（Strength of Weak Ties）— 对应信息分层传播中 Propagation_Only 层级
3. 每个理论必须说明：
   - 理论核心观点（1-2 句）
   - 对应到 MiroConsumer 的哪个设计点
   - 当前实现是工程近似而非严格复现的声明
4. 在方法论限制声明中增加「仿真设计基于工程近似，非严格学术复现」

### 不要做什么
- 不宣称仿真结果具备统计代表性
- 不把理论引用写成营销话术
- 不改动代码

## 验收标准
1. PRD.md 中至少有 3 个理论引用，每个有参考文献
2. 每个理论映射到具体设计点
3. 方法论限制声明中包含工程近似声明
