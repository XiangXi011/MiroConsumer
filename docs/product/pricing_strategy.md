# Consumer Test Pricing Strategy

This note supports P1-012 by connecting differentiated pricing to real differences in simulation logic.

## differentiated pricing rationale

The product can only justify differentiated pricing when each test type exposes distinct analysis mechanics. P1 specialization creates that foundation:

- Packaging Test includes visual attention and shelf context signals.
- Price Test includes Gabor-Granger price acceptance and elasticity signals.
- A/B Test includes paired comparison, ranking, and preference strength.
- Copy Test includes headline, body, and CTA element scoring.
- Concept Test remains the baseline concept resonance workflow.

## Packaging and Copy tiers

Packaging and Copy can be priced above the baseline when reports expose their specialized perception-layer outputs. Packaging should include visual attention heatmap interpretation. Copy should include element-level copy diagnostics.

## Price Test tier

Price Test should be positioned as a higher-value quantitative tier because it uses a Gabor-Granger style decision path. The report should disclose observed price, reference price, price sensitivity segment, acceptance probability, and elasticity signal.

## A/B Test tier

A/B Test should be positioned as a comparison tier because it uses paired comparison rather than a generic one-option reaction. Reports should include variant scores, ranking, preference strength, and notes about choice-set independence.

## Guardrails

Pricing language must not claim real-market prediction. The correct claim is that specialized agent-based signals provide better directional diagnostics than prompt-only generic simulations.
